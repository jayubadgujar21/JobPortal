# JobPortal

JobPortal is a backend project built with **Spring Boot** and **MySQL**, designed to manage job postings, applications, and employee–employer interactions.  
It provides REST APIs that can be integrated with any frontend (React, Angular, etc.).

## ✨ Features
- User Registration & Authentication (JWT-based security)
- Post new jobs (by employers)
- Search & filter jobs (by employees)
- Save & apply for jobs
- Manage applied jobs
- Admin role for monitoring the portal

## 🛠 Tech Stack
- **Java 17**
- **Spring Boot 3.x**
- **Spring Data JPA (Hibernate)**
- **Spring Security (JWT)**
- **MySQL**
- **Maven**

## 🚀 Future Enhancements
- Email notifications for job applications
- Role-based dashboards
- Resume upload & parsing
